# 🏰 Mini Dungeon Visual Project

A fun and interactive **Mini Dungeon** adventure built with **HTML**, **CSS**, and **JavaScript**. This project simulates a basic dungeon-crawling experience where players navigate rooms, encounter events, and visualize their progress.

---

## 🎮 Features

- 🧱 Grid-based dungeon layout (2D visual map)
- 🧍‍♂️ Player movement with arrow keys
- 🔄 Dynamic room interactions (traps, treasure, enemies)
- ✨ Visual effects and animations
- 📱 Fully responsive layout (mobile + desktop)

---

## 🛠️ Technologies Used

- **HTML5** – for structure and layout
- **CSS3** – for styling, visual effects, and transitions
- **JavaScript (Vanilla)** – for logic, interactions, and game mechanics
