Nyumbani Manager: rentals in Kenya

  • React
  • TypeScript
  • Vite
  • Tailwind
  • Supabase
  • Postgres RLS
  • Vitest
  • Playwright

In active development in 2026. The repository is private; this page describes the design.

The problem

In Kenya, finding a rental and running one happen in different places: listings on one site, rent tracked in a notebook or a WhatsApp thread. Nyumbani Manager does both. Tenants find a home and then see what they owe. Landlords list properties and then run their rent roll.

What it does

  • Search: by county, area, rent in shillings, size and amenities, with filters kept in the URL so a search can be shared.
  • Tenants: link a tenancy with a landlord's invite code, then see what's due and when, a "your rent is late" banner, payment history, receipts and the deposit held.
  • Landlords: a monthly rent page in Nairobi time, a rent roll with status, balance and days overdue, arrears ageing, a six-month collection chart, CSV export, a printable statement, and reminders ready to paste into WhatsApp or SMS.
  • Admins: moderate listings, verify landlords and read the audit log. They deliberately cannot see tenancies or payments.

Security lives in the database

With Supabase the browser talks to Postgres directly, so row-level security is the real permission system. Getting it wrong leaks one tenant's rent to another. I treated those rules as the most important code in the project:

  • All 12 migrations are applied to an embedded Postgres in the test suite. More than 200 database tests then run real SQL as each kind of user (signed-out visitor, tenant, another tenant, landlord, admin) and check what each can read and write.
  • A mutation check proves the tests have teeth. It copies the migrations, breaks one protection at a time, and fails if the suite still passes.
  • Money is stored in cents, and rent maths lives in small pure functions with their own unit tests.

How it was built

  • CI on every pull request: typecheck, lint, unit tests, database tests and build, then Playwright journeys.
  • axe accessibility checks on every main screen at phone and desktop width.
  • Every user-visible string is kept in one place so a Swahili translation can be added beside it.
  • An honest scope line in the README: rent tracking is a record, not a payment service, and no money moves through the app yet.
