Client build · 2026

Custodial wallet & trading platform

  • Postgres

How I work

Tests decide what ships

Access rules tested as the user who would break them, money flows that can't apply twice, and CI on every pull request.

AI-assisted, not AI-trusting

Claude Code is my main tool, run with project instructions, tests and accessibility checks in the loop. It writes a lot of code; the tests decide whether it stays.

Written down

Architecture notes, plain-language READMEs and status tables that say what is done and what isn't. I've written two full courses, so explaining is part of the job.
